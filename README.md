<h1 align="left">To-Do Application</h1>


<h2 align= "left"> <img src="frontend/favicon.svg" width="24" height="24" style="vertical-align: bottom;"> Full-featured task management web application with folder support, drag-and-drop ordering, customizable folder colors, multi-language interface, and Google authentication.</h2>

<h2 style="display: flex; align-items: center;">
  <img src="kitten.gif" width="32" height="32" style="vertical-align: middle; margin-right: 10px;">
  <span style="line-height: 32px;">Features</span>
</h2>

- **Authentication** — email/password registration and login; Google Sign-In via Firebase.
- **Folders** — create, rename, delete folders; assign one of 14 border colors.
- **Tasks** — full CRUD with optimistic UI updates; checkboxes toggle completion instantly.
- **Drag-and-drop** — reorder folders and tasks using SortableJS; order persisted on the server.
- **Theming** — light and dark mode; toggle via a monochrome icon button.
- **Localization** — three languages supported: English, Russian, Karakalpak (kaa).
- **Responsive design** — adapts to desktop, tablet, and mobile screens.
- **Custom modal dialogs** — styled confirmations and prompts replace native browser dialogs.
- **Loading indicator** — spinner appears only for requests exceeding 700 ms, avoiding flicker.
